# Agent guide: .github

Organization-wide default issue forms, pull request template and profile. Organization rules are in
the organization handbook (`handbook/AGENTS.md`); its strict rules apply here.

- This repository is **public**. Never add anything sensitive, internal or specific to one repository.
- Changes here affect every repository without its own templates. Keep issue forms consistent with
  the handbook's ways of working, and update both in the same feature.
